# 宿主机固定预览地址（长期可用）

**地址：<http://codex.ts.nnnn.tech:58080/>**

改完 `index.html` 直接刷新即可，无需重新部署（页面读取的是磁盘上的同一个文件）。

## 为什么用这个地址

| 端口 | 外网可达 | 说明 |
| --- | --- | --- |
| 22222 | ✅ | SSH |
| **58080** | ✅ | BT nginx 站点端口，本项目的固定入口 |
| 888 / 9876 | ✅ | 已被其他服务占用 |
| 80 / 443 / 8077 / 18099 | ❌ | 实测外网连接超时（路由器未转发） |

> Cloudflare 快速隧道（`*.trycloudflare.com`）**每次重连都会换随机地址**，只适合临时分享；长期演示用上面的固定地址。

## 组成

1. **静态文件**：宿主机 `/home/tree/web113/index.html` 是指向项目文件的符号链接：
   ```
   /home/tree/web113/index.html -> /home/tree/codex/project/projects/113/index.html
   ```
   （容器里的 `/workspaces/projects/113/index.html` 就是宿主机这个文件。）

2. **常驻静态服务**（用户级 systemd，已 `enable`，`Linger=yes` 开机自启）：
   ```
   ~/.config/systemd/user/selfheal-113.service
   ExecStart=/usr/bin/python3 -m http.server 18113 --bind 127.0.0.1 --directory /home/tree/web113
   ```

3. **BT nginx 反向代理**：`/www/server/panel/vhost/nginx/selfheal-113.conf`
   ```nginx
   server {
       listen 58080;
       listen [::]:58080;
       server_name codex.ts.nnnn.tech;
       add_header Cache-Control "no-store";
       location / {
           proxy_pass http://127.0.0.1:18113;
           proxy_http_version 1.1;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
       }
   }
   ```
   同一端口上的其他 Host（如 `nnnn.tech:58080`）仍走原有的 `server_name _` 站点，互不影响。

## 运维命令

```bash
# 查看 / 重启静态服务（宿主 tree 用户）
systemctl --user status  selfheal-113.service
systemctl --user restart selfheal-113.service

# 改完 nginx 配置后
sudo /www/server/nginx/sbin/nginx -t -c /www/server/nginx/conf/nginx.conf
sudo /www/server/nginx/sbin/nginx -s reload -c /www/server/nginx/conf/nginx.conf
```
