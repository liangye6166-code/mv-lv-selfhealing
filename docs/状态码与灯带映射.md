# 状态码与沙盘灯带映射

本工具是**中低压协同自愈演示底座**：每一步动作都会输出稳定、可枚举的状态码，
便于映射到物理沙盘的 LED 灯带。全部状态码由 `window.__api.status()` 一次取回。

```js
window.__api.status()
// {
//   step: 'ISOLATE',            // 当前步骤码
//   templates: 'petal2',        // 当前网架模板
//   voltageLevel: 'MV/LV',      // 当前网架同时含中压与低压设备
//   fault: { kind:'wire', id:'w12', label:'电缆故障', scene:'L1 …',
//            tripped:[…], iso:[…], restored:[…] } | null,
//   loads: { total:20, live:20, dead:0, lvAffected:0 },   // lvAffected = 失电建筑负荷数
//   dev: { SUBA:'ENERGIZED', A1:'DEENERGIZED', … },        // 图元状态
//   sw:  { 'A1:bt':'SWITCH_OPEN', 'A1:u1':'SWITCH_CLOSED', … } // 开关状态
// }
```

## 1. 步骤码 `step`

| 状态码 | 含义 | 灯带建议 |
| --- | --- | --- |
| `IDLE` | 未开始 / 已复位 | 按当前通断常亮 |
| `PROTECT` | ① 保护动作、切除故障侧电源 | 故障段**红闪** |
| `ISOLATE` | ② 隔离完成（瞬时故障时为重合闸成功） | 隔离点两端**橙闪** |
| `RESTORE` | ③ 转供合闸成功（有备用通道动作） | 转供通道**绿闪** |
| `DONE` | ③ 完成但无需合闸（故障已被切除/无需转供） | 恢复常亮 |

> 三条入口（`① ② ③` 按钮 / 单步 / 自动演示）共用同一状态机，同一场景下步骤码一致。

## 2. 图元状态 `dev[*]`

| 状态码 | 含义 | 灯带建议 |
| --- | --- | --- |
| `ENERGIZED` | 带电（母线有压 / 负荷已复电） | 常亮 |
| `DEENERGIZED` | 失电 | 灭 |
| `FAULT` | 该图元处在故障区间上 | **红闪** |

## 3. 开关状态 `sw[*]`

| 状态码 | 含义 | 灯带建议 |
| --- | --- | --- |
| `SWITCH_CLOSED` | 断路器/负荷开关**合位** | 亮 |
| `SWITCH_OPEN` | **分位**（含开环点、隔离点） | 灭 |
| `TIE_CLOSED` | **常开联络开关合上**（转供通道） | 橙亮 |

母联（分段）开关属于常开联络，正常为 `SWITCH_OPEN`；备自投动作后为 `TIE_CLOSED`。
低压母联 `DS1_BT` 同样是一个独立的 `bzt` 开关：一段 0.4 kV 母线失压、另一段有压时合闸；
母线故障 / 配变故障时闭锁，状态仍为 `SWITCH_OPEN`，不得向故障区间反送。

## 4. 颜色 ↔ 状态（画面与灯带同源）

| 画面语义 | 颜色 | 对应状态码 |
| --- | --- | --- |
| 花瓣Ⅰ 带电 | 蓝 | `ENERGIZED`（Ⅰ段） |
| 花瓣Ⅱ 带电 | 青 | `ENERGIZED`（Ⅱ段） |
| 失电（三角转灰、无潮流箭头） | 灰 | `DEENERGIZED` |
| 合位 | 实心圆/实心方框 | `SWITCH_CLOSED` |
| 分位 | 空心 + 「分」徽章，橙 | `SWITCH_OPEN` |
| 母联常开 / 转供合上 | 橙 | `SWITCH_OPEN` / `TIE_CLOSED` |
| 故障点 | 红 + 脉冲晕 + 圆内序号 | `FAULT` |
| 0.4 kV 低压设备 / 线路 / 建筑 | 琥珀 | 随所在节点输出 `ENERGIZED` / `DEENERGIZED` |

`dsub`（样板配电房 DS1）按整组带电状态输出，`rmu`（环网箱）与 `bld`（建筑负荷）按各自
母线 / 进线端子输出；建筑负荷失电时计入 `loads.dead` 与 `loads.lvAffected`。

## 5. 外部桥接示例

```js
// 轮询（1 Hz）驱动灯带
setInterval(function(){
  var st = window.__api.status();
  strip.setStep(st.step);                      // 步骤灯
  for (var id in st.dev) strip.setNode(id, st.dev[id]);
  for (var k in st.sw)   strip.setSwitch(k, st.sw[k]);
}, 1000);
```

对纯硬件沙盘：把 `status()` 的结果按 `dev` / `sw` 的键位接成灯带地址即可，
无需理解内部仿真逻辑。
