# 接线约定（电气）

本文档规定工作台中各图元的画法与接线规则，避免图形表达与电气含义脱节。
电气依据：《“双花瓣”配电网网络结构介绍》（广州 / 苏州高可靠性示范区做法）、
CPEM《10kV 新型网架结构——“花瓣式”》。

## 1. 图元（与典型设计图一致）

### 1.1 变电站（10 kV 电源点）

- 画法：**圆角方框** + 内部 **主变** + **加粗的 10 kV 母线** + 母线端头的**母线终端**方块；
  主变左侧一小段**上级进线**示意（不作接线用），主变下方标「**主变**」二字，避免与互感器混淆。
- **主变符号必须是“两个相交的圆”**（双绕组变压器，GB/T 4728.4 / IEC 60617），并在旁边标注文字。注意区分：
  | 符号 | 含义 |
  | --- | --- |
  | 两个**相交**的圆 | **双绕组变压器**（本项目用） |
  | 三个相交的圆 | 三绕组变压器 |
  | 两个**同心**的圆 | **自耦变压器**（不要用于常规主变） |
  | 一个圆 + 穿心直线 | 电流互感器（CT） |
  | 两个相交圆 + 一次/二次引出 | 电压互感器（PT） |
- 出线：**2 回** 10 kV 电缆（出线1、出线2），引自**同一段母线**；电缆末端为**电缆终端头**（端子：白环 + 实心圆）并标注
  **示意性馈线编号**（不使用真实线路号）。
- 约束：一个节点不得并出两根线；双花瓣中这两回出线是**同一片花瓣**的两端电源。

### 1.2 开关站（环网柜 / 开闭所）

- 画法：**单母线分段**——**Ⅰ 段母线**（左）与 **Ⅱ 段母线**（右）**共线横置**，中间为
  **母联**（分段开关，见 1.4）；两段母线外端各画**母线终端**。
- 每段母线的间隔（共 4 个）：
  - **2 回用户出线**，朝**外**（背离环网通道）引出，供本站配电房；
  - **2 回环网间隔**，朝**内**（朝向环网通道）引出，一进一出串接花瓣。
- 因此单站 = **2 进 2 出环网间隔 + 4 回用户出线间隔 + 1 个母联间隔**，
  与典型设计图“每段母线两路进线开关 + 一路出线开关”的环网柜画法一致。
- **母线终端**：母线在端头被绝缘封堵 —— 母线末端画**一个小实心方块**（避免与开关符号混淆）。
- **进 / 出线标注**：按该站所在花瓣的**实际潮流方向**自动对名（自左向右的环，
  Ⅰ 段进线在左；自右向左的环，Ⅱ 段进线在右），保证“进线”永远指向上游。
- 朝向：整体**不允许任意角度旋转**；右键菜单提供“上下镜像（Ⅰ / Ⅱ 段互换位置）”，
  下排开关站镜像后用户朝下、环网间隔朝上。
- 图元大小可用顶栏“图元大小”滑杆统一缩放。

### 1.3 配电房（用户）

- 画法：**一个用户出线间隔 = 一个独立负荷**，各画**一个三角形**（顶点背向开关站，上排朝上、下排朝下），
  符号取所属母线段颜色（Ⅰ 段蓝 / Ⅱ 段青）。每座开关站 4 个用户间隔 → **4 个独立负荷（配电房）**。
- **单电源**：每个负荷只由它自己那一回用户出线供电，**该回路失电即失电、线路与符号一起转灰**；
  某回分支电缆故障 → 由该用户出线开关切除，只损失这一个负荷，不影响同一母线段上的其它负荷。

### 1.3b 变压器 / 开关 / 母线（元件库里的独立元件）

用于**自建网架**（自定义模板）时搭出单母线、单母线分段、链式等常见接线。

- **变压器**：**双绕组**符号——**两个相交的圆**（GB/T 4728.4 / IEC 60617）；
  **一次侧（高压）**与**二次侧（低压）**各 1 个端子，属**导体、恒通**
  （变压器本身不是开关，分合由两侧的断路器 / 负荷开关承担）。
  数据层：两个端子均带 `nosw:true`，`simulate()` 恒把它们并入本站母线节点。
- **开关**：**长方形框**——**空心 = 分位（断开）、实心 = 合位（闭合）**，与母联、间隔断路器同一套画法。
  A / B 两端子，**单状态**（`closed`）：点框体即分 / 合，拖动框体是移动图元；
  可**旋转 0° / 90°** 竖装，用作断路器、负荷开关、分段开关、隔离开关；
  右键「设为常开联络开关」后两端子置 `tie`、分位画成**橙色虚线框**，
  状态码按 `TIE_CLOSED / SWITCH_OPEN` 输出（详见《状态码与灯带映射》）。
- **母线**：**加粗导体**，**左端 / 右端 / 中间引下共 3 个端子**，均 `nosw:true`（恒通、不可分断）；
  用于把多回进出线汇接到同一段母线上（自建单母线 / 单母线分段）。
- **禁止同一图元的两个端子互接**：拖拽吸附与「点选两端」两条接线路径都会拦下并提示。
  需要“自环”时请用两只开关 / 一段母线过渡。

### 1.4 电缆与走线

- 电缆：**横平竖直的正交折线**（不使用曲线），转角处小圆角；按所属花瓣着色
  （花瓣Ⅰ 蓝 `#1d4ed8`，花瓣Ⅱ 青 `#0d9488`）。
- 并行电缆分层：相邻站环网间隔之间的主干电缆按 `bias` 分道走线，花瓣Ⅱ 整体外移一层，
  与花瓣Ⅰ 分层不重叠。
- 接线落点必须落在**端子**上（沿端子方向直进直出），不得悬空。
- **断路器**：**实心矩形 = 合位**（取母线段颜色，失电转灰）；**空心矩形 = 分位**（不旋转、不歪头）。
- **母联（分段开关）**：横置于两段母线之间，用**横置长条方框**表示——
  **空心方框 = 分位（断开）**、**实心方框 = 合位（闭合）**（方框颜色随母线段状态：合位取带电色，失电转灰）。
  双花瓣正常方式为**分位（常开）**，两段母线互为备用，一段失电时经母联备自投由另一段接带。

## 2. 接线规则

1. **花瓣成环**：`变电站出线1 → 首站环网进线`，`站k 环出 → 站k+1 环进`，……，
   经**纵向联络**换排后继续串联，`末站环出 → 变电站出线2`，首尾回到**同一座变电站的同一段母线**，
   闭合成环 → 这就是**一片花瓣**。
2. **双花瓣 = 两片花瓣相切**：花瓣Ⅰ 串各站 **Ⅰ 段母线**、由变电站1 两回出线供电；
   花瓣Ⅱ 串各站 **Ⅱ 段母线**、由变电站2 两回出线供电；两片花瓣在**每座开关站**经母联开关相切。
3. **纵向联络**：上排与下排之间由两处纵向联络电缆连接（开关站2 Ⅰ 段 ↔ 开关站4 Ⅰ 段；
   开关站1 Ⅱ 段 ↔ 开关站3 Ⅱ 段），是花瓣“折返”换排的唯一通道。
   两处纵向联络各占**独立走线通道**，与主干电缆不共线。
4. **花瓣间联络**：两片花瓣之间**只通过开关站的母联开关**互联，正常**常开**；
   一段母线失电时合上母联，由另一段母线转供（母联备自投）。
5. **运行方式**：正常方式 **环网合环运行、母联断开**；
   可在工具栏切换“环网开环 / 环网闭环”以对比负荷率与短路电流的差别。
6. **禁止并列**：任何时候不得出现两座变电站经环网并列（`双电源并列` 告警）。

## 3. 典型接线模板

| 模板 | 电源点 | 结构 | 转供能力 |
| --- | --- | --- | --- |
| 双花瓣（4 站） | 2 | 两排共 4 座开关站（开闭站）；两片花瓣各由一座变电站同一段母线的 2 回出线经纵向联络成环，相切于母联 | 最强，线路任一段故障**不停电** |
| 单花瓣（5 站） | 1 | 1 座变电站两回出线 + 各站 Ⅰ 段母线成环，母联合闸带 Ⅱ 段负荷 | 站内 / 环内转供 |
| 双环网 | 2 | 甲乙各 1 个环（开环运行），环间 1 处联络开关（经两环 Ⅱ 段母线） | 跨环转供 |
| 单环网 | 1 | 1 个环，同一段母线两回出线成环，设 1 处开环点 | 环内转供 |
| 单辐射 | 1 | 单电源链式，无联络 | 无 |

## 4. 故障处理顺序

1. **故障发生 · 保护动作**
   - **线路（电缆）故障**：光纤电流差动保护**瞬时切除故障电缆两端开关**，故障区间与系统解列；
     合环运行下非故障段继续供电，**通常不损失负荷**。
   - **开关站母线故障**：母线差动保护跳开与该段母线连接的**全部开关**，并**闭锁母联备自投**
     （不得向故障母线反送电）。
   - **变电站母线故障**：该站全部出线跳闸，电源全停。
2. **故障隔离**：确认故障区间两端已形成明显断开点；母线故障还需拉开母联、闭锁备自投。
3. **转供恢复**：
   - **母联备自投（按站独立动作）**：故障后**逐座**检查开关站——只要本站**一段母线失压、另一段有压**，
     即合上本站母联，由另一段母线接带本站负荷。上级变电站全停时位于该花瓣的各站母联**各自动作**；
     本站两路进线同时失电时只动本站母联；线路（电缆）故障时两段母线均有压，母联不动作。
   - 每合一座母联都校验**不造成两电源并列、不向故障区间送电**，越限即闭锁；母线故障则整站母联被闭锁。
   - 其余场景在“不并列、不向故障区间送电”的前提下合上备用通道，最大化恢复非故障段供电；
     以“带电节点数”为增益搜索，环间联络等**需两级开关串联**的通道也能被逐步接通。
   - 动作时刻与内容写入**竖向时间轴**（`0.00 s` 故障发生，`+0.35 s` 隔离，`+1.20 s` 转供）。

### 4.1 开关拒动 / 保护拒动（越级）

- **开关站内环网开关拒动**（场景 K3）：本侧无法切除故障 → **后备保护越级**跳开该站**该段全部进出线开关**
  并**闭锁母联**，故障由后备保护切除；该段母线所带配电房失电，带故障转供被闭锁，须人工隔离。
- **变电站出线开关拒动**（场景 R1）：越级跳开本站**全部出线**，变电站全停；各站母联备自投随后由另一花瓣转供。
- 文案按“拒动 / 母线 / 变电站 / 电缆 / 分支电缆”分支生成，失电户数与开关实态始终一致。

### 4.2 三条入口同源

① 模拟故障 / ② 隔离故障 / ③ 转供恢复、**单步**、**自动演示**共用同一演练状态机（`FAULT.phase`）。
无论走哪条入口，结束时**开关实态、失电户数、右侧步骤状态、左侧时间轴与底栏文案完全一致**；
演练结束后再点“单步”会提示先复位，不会在开关已拉开的状态下重跑 ①。
底栏“运行方式 / 校验条”由**环网开关与母联的真实位置**驱动；双花瓣 / 单花瓣无环网开环点，
“环网闭环 / 开环”按钮置灰并说明（开环点由母联承担）。

### 4.3 自愈失败与故障性质（场景修饰）

演练场景库按**演示主线**分为六类：线路故障 → 开关站故障 → 电源故障 → 自愈失败 →
故障性质 → 运行方式与二次异常。以下为各“非典型”情况的处理口径：

- **母线故障分段**（K1 / K4）：母线差动跳开**故障段**全部间隔并闭锁母联，只影响该段所带配电房；
  另一段由另一花瓣照常供电。
- **母联备自投拒动**（M1）：一段母线失压但本站母联**未动作** → 该段无法转供，所带配电房持续失电，
  须人工合闸或检修。与 K2（备自投成功）对照演示。
- **转供容量不足**（M2）：备用花瓣（对侧馈线）**载流受限**时，先按拓扑**复电**，再按可用容量
  **限电**——拉开超出的用户出线开关。结果 = “恢复 N 户 + 限电 M 户”，与文案中“只能转供 N 个配电房”一致。
  注意：双花瓣的 Ⅰ 段是一条**成环**母线，合上任意一座母联即整环有电，故不能按“合了几座母联”估算容量。
- **差动保护通道故障**（M3）：主保护闭锁 → 只能由变电站出线**过流后备保护越级**，
  跳开变电站两回出线、花瓣全停（8 户），再由母联备自投转供；与 L2（主保护正确动作、不停电）形成对照。
- **单相接地**（F1）：10 kV 小电流接地系统**单相接地不跳闸**，仅选线装置告警；
  由运行人员**试拉**逐条线路确认，确认后隔离。合环 / 有联络网架下非故障段不停电；
  单辐射网架试拉即造成故障段下游短时停电，且隔离后无法转供，须待修复。
- **重合闸**：瞬时性故障（T1）跳闸 → `+0.60 s` 重合成功 → 恢复，停电时间约 0.6 s；
  永久性故障（T2）跳闸 → 重合**不成功** → 加速跳闸 → 再隔离并转供。
- **保护误动 / 开关偷跳**（M4）：线路**无故障**却跳闸，无可隔离区间，可直接**强送**恢复。
- **上级电源全停**（P3）：两座变电站同时失电，全网无备用电源，须待上级电源恢复。
- **预置运行方式**：O1 预置**开环点**（故障必然停电，须合开环点 / 母联转供）；
  O2 预置**母联常合**（两段并列、两电源并列，校验条告警；母线故障时解列、故障段停电且备自投闭锁）。
  预置方式只作用于当前场景：切换场景时 `sceneReset()` 会**按模板默认**复原母联 / 开环点，
  不会把 O2 的“母联常合”或 O1 的“开环点”带到下一个场景。

## 5. 已知简化（不作现场依据）

- 未做载流量 / 短路容量校核，未做保护定值级差配合。
- 越级跳闸、开关拒动为人工设定的场景修饰：开关站内拒动按“越级跳开该站该段全部进出线 + 闭锁母联”处理，
  变电站出线拒动按“越级跳开本站全部出线（变电站全停）”处理。
- 瞬时性故障的重合闸按“一次重合即成功”处理；永久性故障按“重合一次不成功后加速跳闸”处理，不计重合次数与整定时间。
- **转供容量**只作“可转供户数上限”的示意（限电建模），不做载流量 / 短路容量校核；
  实际以对侧馈线载流能力与保护定值为准。
- 单相接地按“不跳闸 + 人工试拉确认”处理，不模拟选线装置的具体算法与接地电流大小。
- 单花瓣模板按 **5 座开关站** 演示；双花瓣按 **4 座开关站**（上排 2 / 下排 2，共 16 个配电房）演示，可在画布上复制图元自行扩展。
- 备自投按**“按站独立动作”**演示：失压段的各站母联依次合闸，与现场“各站备自投各自动作”一致；
  合闸顺序取最短动作路径，结果与“先合一处、其余被电压闭锁”等价，但更便于演示母联的参与过程。
- 画布上的 ①②③ 动作标记会**自动避让**并画引线连回被标注的开关；同一开关同时参与多步时记作 `1·2`。
- 变电站 10 kV 母线仅画作一段，未区分 Ⅰ / Ⅱ 段母线与分段开关。

## 8. 搭网（元件库）与状态码

### 8.1 元件库

左栏「元件库」提供三类最小图元，拖入画布或点击即加入（点击落在视图中央）：

| 图元 | 说明 |
| --- | --- |
| 变电站 | 10 kV 电源点；默认出线朝右，右键可**左右镜像**换向，或旋转微调 |
| 开关站 | 单母线分段环网柜；加入时自动带出本站 **4 个用户出线配电房** |
| 配电房 / 负荷 | 单电源、一个三角形；需从**进线端子**拖线接到开关站的用户出线端子，否则按**失电**计 |

- 电缆：从图元**端子**拖到另一个端子即成线；拖动线体可调整走线位置。
- 右键电缆可**设为常开联络（分位）**——两端端子标记为联络并置分位，等效于环间/花瓣间的联络开关。
- 「自定义」模板 = **空白网架**；模板本质就是一份 JSON，导出 / 导入即可保存与迁移。

### 8.2 图元与开关状态（数据模型）

设备上预留了低压二期字段：`voltageLevel`（`'MV'` / 预留 `'LV'`）、负荷的 `lvFeederId`（台区）、
`lvAffected`（影响台区数，本期恒为 0）。

每一动作步输出稳定状态码，详见 **[状态码与灯带映射.md](状态码与灯带映射.md)**：

| 类别 | 枚举 |
| --- | --- |
| 步骤 | `IDLE` / `PROTECT` / `ISOLATE` / `RESTORE` / `DONE` |
| 图元 | `ENERGIZED` / `DEENERGIZED` / `FAULT` |
| 开关 | `SWITCH_CLOSED` / `SWITCH_OPEN` / `TIE_CLOSED` |

取法：`window.__api.status()`。
