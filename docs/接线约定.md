# 接线约定（电气）

本文档规定工作台中各图元的画法与接线规则，避免图形表达与电气含义脱节。
电气依据：《“双花瓣”配电网网络结构介绍》（广州 / 苏州高可靠性示范区做法）、
CPEM《10kV 新型网架结构——“花瓣式”》。

## 1. 图元（与典型设计图一致）

### 1.1 变电站（10 kV 电源点）

- 画法：**正方形**框，内部一条**竖置 10 kV 母线**，母线顶端一个电源圆点（矩形图元不符合电气制图习惯）。
- 出线：**2 回** 10 kV 电缆（出线1、出线2），引自**同一段母线**；出线端头画**线路终端**并标注线路名称。
- 约束：一个节点不得并出两根线；双花瓣中这两回出线是**同一片花瓣**的两端电源。

### 1.2 开关站（环网柜 / 开闭所）

- 画法：**单母线分段**——**Ⅰ 段母线**（左）与 **Ⅱ 段母线**（右）**共线横置**，中间为
  **母联**（隔离开关常合 + 断路器，虚线画法见 1.4）；两段母线外端各画**母线终端**。
- 每段母线的间隔（共 4 个）：
  - **2 回用户出线**，朝**外**（背离环网通道）引出，供本站配电房；
  - **2 回环网间隔**，朝**内**（朝向环网通道）引出，一进一出串接花瓣。
- 因此单站 = **2 进 2 出环网间隔 + 4 回用户出线间隔 + 1 个母联间隔**，
  与典型设计图“每段母线两路进线开关 + 一路出线开关”的环网柜画法一致。
- **母线终端**：母线端头的绝缘终端符号（短横 + 竖向端头）。
- **进 / 出线标注**：按该站所在花瓣的**实际潮流方向**自动对名（自左向右的环，
  Ⅰ 段进线在左；自右向左的环，Ⅱ 段进线在右），保证“进线”永远指向上游。
- 朝向：整体**不允许任意角度旋转**；右键菜单提供“上下镜像（Ⅰ / Ⅱ 段互换位置）”，
  下排开关站镜像后用户朝下、环网间隔朝上。
- 图元大小可用顶栏“图元大小”滑杆统一缩放。

### 1.3 配电房（用户）

- 画法：小房子（房体 + 屋顶），屋顶背向开关站；房内标注 **Ⅰ / Ⅱ** 表示所接母线段。
- **双回路进线**：两回电缆分别引自本站**同一段母线**的两回用户出线间隔，
  任一回带电即视为不停电；分支电缆故障只损失一路，用户不停电。

### 1.4 电缆与走线

- 电缆：正交走线 + 圆角，按所属花瓣着色（花瓣Ⅰ 蓝 `#1d4ed8`，花瓣Ⅱ 青 `#0d9488`）。
- 环网主干：相邻站环网间隔之间的长电缆自动走成**花瓣回流弧**；花瓣Ⅱ 的弧线整体外移一层，
  与花瓣Ⅰ 分层不重叠。
- 接线落点必须落在**端子**上（沿端子方向直进直出），不得悬空。
- **断路器**：实心矩形 = 合位（取母线段颜色，失电转灰）；空心斜置 = 分位。
- **母联**：横置于两段母线之间的隔离开关（实心小方）+ 断路器（状态方框），正常**常开**。

## 2. 接线规则

1. **花瓣成环**：`变电站出线1 → 首站环网进线`，`站k 环出 → 站k+1 环进`，……，
   经**纵向联络**换排后继续串联，`末站环出 → 变电站出线2`，首尾回到**同一座变电站的同一段母线**，
   闭合成环 → 这就是**一片花瓣**。
2. **双花瓣 = 两片花瓣相切**：花瓣Ⅰ 串各站 **Ⅰ 段母线**、由永福变两回出线供电；
   花瓣Ⅱ 串各站 **Ⅱ 段母线**、由庙前变两回出线供电；两片花瓣在**每座开关站**经母联开关相切。
3. **纵向联络**：上排与下排之间由两处纵向联络电缆连接（泊云站 Ⅰ 段 ↔ 枫翠站 Ⅰ 段；
   学术站 Ⅱ 段 ↔ 昌源站 Ⅱ 段），是花瓣“折返”换排的唯一通道。
4. **花瓣间联络**：两片花瓣之间**只通过开关站的母联开关**互联，正常**常开**；
   一段母线失电时合上母联，由另一段母线转供（母联备自投）。
5. **运行方式**：正常方式 **环网合环运行、母联断开**；
   可在工具栏切换“环网开环 / 环网闭环”以对比负荷率与短路电流的差别。
6. **禁止并列**：任何时候不得出现两座变电站经环网并列（`双电源并列` 告警）。

## 3. 典型接线模板

| 模板 | 电源点 | 结构 | 转供能力 |
| --- | --- | --- | --- |
| 双花瓣（9 站） | 2 | 两排共 9 座开关站；两片花瓣各由一座变电站同一段母线的 2 回出线经纵向联络成环，相切于母联 | 最强，线路任一段故障**不停电** |
| 单花瓣（5 站） | 1 | 1 座变电站两回出线 + 各站 Ⅰ 段母线成环，母联合闸带 Ⅱ 段负荷 | 站内 / 环内转供 |
| 双环网 | 2 | 甲乙各 1 个环（开环运行），环间 1 处联络开关（经两环 Ⅱ 段母线） | 跨环转供 |
| 单环网 | 1 | 1 个环，同一段母线两回出线成环，设 1 处开环点 | 环内转供 |
| 单辐射 | 1 | 单电源链式，无联络 | 无 |

## 4. 故障处理顺序

1. **故障发生 · 保护动作**
   - **线路（电缆）故障**：光纤电流差动保护**瞬时切除故障电缆两端开关**，故障区间与系统解列；
     合环运行下非故障段继续供电，**通常不损失负荷**。
   - **开关站母线故障**：母线差动保护跳开与该段母线连接的**全部开关**，并**闭锁母联备自投**
     （不得向故障母线反送电）。
   - **变电站母线故障**：该站全部出线跳闸，电源全停。
2. **故障隔离**：确认故障区间两端已形成明显断开点；母线故障还需拉开母联、闭锁备自投。
3. **转供恢复**：
   - **母联备自投**：某段母线的**两路进线同时失电**时，断开该段两路进线开关、**合上母联开关**，
     由另一段母线接带该段负荷。
   - 其余场景在“不并列、不向故障区间送电”的前提下合上备用通道，最大化恢复非故障段供电。

## 5. 已知简化（不作现场依据）

- 未做载流量 / 短路容量校核，未做保护定值级差配合。
- 越级跳闸、开关拒动为人工设定的场景修饰，按“该站全停”处理。
- 瞬时性故障的重合闸按“一次重合即成功”处理。
- 单花瓣模板按 **5 座开关站** 演示；双花瓣按 **9 座开关站**（上排 5 / 下排 4）演示，可在画布上复制图元自行扩展。
- 备自投按“最少合闸次数、恢复最多负荷”演示（同段母线为电气连通体，合一处母联即可恢复整段），
  工程上由各站备自投各自动作，结果等价。
- 变电站 10 kV 母线仅画作一段，未区分 Ⅰ / Ⅱ 段母线与分段开关。
