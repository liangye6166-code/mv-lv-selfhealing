# 双花瓣配电网 · 仿真工作台

面向 **10 kV 中压配电网典型接线** 的可编辑、可仿真、可演练的单页工作台。
零依赖、零构建，双击 `index.html` 即可运行（推荐 Chrome / Edge）。

## 快速开始

```bash
# 方式一：直接打开
open index.html            # macOS
start index.html           # Windows

# 方式二：起一个本地静态服务（推荐，避免个别浏览器对 file:// 的限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080/
```

## 功能一览

| 模块 | 能力 |
| --- | --- |
| 接线拓扑 | 内置 **双花瓣 / 单花瓣 / 双环网 / 单环网 / 单辐射** 五种模板，可自由编辑 |
| 绘图编辑 | 拖动图元、拖动电缆改走线、端子间拖拽接线、复制/粘贴、旋转/翻转 |
| 视图 | 画布缩放、平移、适应窗口、专注画布 |
| 仿真 | 并查集连通性 + BFS 潮流，实时母线/端子带电判定与潮流方向 |
| 故障演练 | 11 组预置场景（线路 / 开关站 / 电源 / 瞬时性 / 保护拒动），①模拟 ②隔离 ③转供 三部动画 |
| 校验告警 | 双电源并列、环网开环点、失电范围、备用间隔统计 |
| 存档 | 导出/导入 JSON，浏览器本地存档（localStorage） |

## 图元约定

- **变电站（10 kV 电源）**：正方形，内部竖置母线，出线 2 回。
- **开关站**：横置母线 + **2 回进线 + 4 回出线**；2 回进线始终朝向花瓣/环网内侧，4 回出线朝外接配电房。
- **配电房（负荷）**：三角形，三角形尖端朝向供区外侧（上方的朝上、下方的朝下）。
- **联络开关**：橙色虚线，常开；跨花瓣/跨环网仅此一处。

详见 [`docs/接线约定.md`](docs/接线约定.md)。

## 快捷键

| 按键 | 作用 |
| --- | --- |
| 滚轮 / `+` `-` | 缩放画布 |
| 空白处拖动 | 平移画布 |
| `Ctrl/⌘ + Z` | 撤销 |
| `Ctrl/⌘ + C` / `V` / `D` | 复制 / 粘贴 / 原地复制选中图元 |
| `Delete` | 删除选中的电缆或图元 |
| `R` / `Shift + R` | 旋转选中图元 ±15°（开关站为翻转） |
| `F` | 适应窗口 |
| `Esc` | 关闭菜单 / 取消选中 |
