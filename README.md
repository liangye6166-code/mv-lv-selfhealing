# 中低压协同自愈 · 仿真工作台

面向 **10 kV / 0.4 kV 配电网典型接线** 的可编辑、可仿真、可演练的单页工作台；
当前重点演示 **中低压协同自愈**——中压侧故障「隔离 → 转供」，以及低压配变 / 母线 / 出线故障的处理。
双花瓣网架内置一个可演练的 **10/0.4 kV 双变样板配电房 DS1** 和一个 **10 kV 环网箱 RM1**。
零依赖、零构建，双击 `index.html` 即可运行（推荐 Chrome / Edge）。

## 快速开始

```bash
# 方式一：直接打开
open index.html            # macOS
start index.html           # Windows

# 方式二：起一个本地静态服务（推荐，避免个别浏览器对 file:// 的限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080/
```

## 界面布局

整体是一套 **IDE 式三段壳层**：**① 标题栏（薄）/ ② 中间区 = 左栏 │ 画布 │ 右栏 / ③ 状态栏（薄）**，
整页不滚动、无浏览器白边。

```
┌──────────────────────────────────────────────────────────────────┐
│ 品牌 文件 编辑 视图 演练 帮助             符号比例 · 亮 / 暗 / 跟随 │ ① 标题栏
├────┬──────────────┬──────────────────────────┬───────────────────┤
│图元│ 元件库        │                          │ 元件属性 │ 动作过程 │
│图标│ 网架结构 ★默认 │      绘图 / 仿真画布      │ ────────────────  │ ② 中间区
│条  │ 故障演练      │ （可缩放 / 平移 / 右键）  │ 选中图元属性 /    │ 左栏│画布│右栏
│☰☰☰│ (竖向图标切换) │                          │ 竖向时间轴 ① ② ③  │ 分隔条可拖
├────┴──────────────┴──────────────────────────┴───────────────────┤
│ 运行方式 合环 · 母联常开 │ 拓扑芯片 │ 校验/告警 │ 缩放 图元 主题    │ ③ 状态栏
└──────────────────────────────────────────────────────────────────┘
```

- **① 标题栏**：品牌 + 菜单（文件 / 编辑 / 视图 / 演练 / 帮助）+ **符号比例**滑杆 + **主题切换（亮 / 暗 / 跟随系统）**。高度用 `clamp()`，桌面约 `2–2.25rem`，是一条薄的软件标题栏。
- **② 中间区**：唯一主工作区，水平三栏。左栏 / 右栏夹在**分隔条**之间——**拖分隔条改宽度**（约 200–480 px）、**点分隔条上的箭头（或双击分隔条、或用「视图」菜单）折叠 / 展开**；宽度与折叠状态按断点存 `localStorage`，刷新保持。
  - **左栏 = 竖向图标条 + 一页内容**（借鉴 IDE 活动栏）：`元件库`（拖拽搭网）· `网架结构`（预设 / 自定义，**默认页**）· `故障演练`（场景库**分组列表**：左列代号 `L1/K1/P1`、右列摘要，选中项在面板内显示**全称**）；点图标条切换页面，也可用「视图」菜单里的同名项切换。
  - **右栏 = 横向标签页**：`元件属性`（默认页：属性 / 编辑 / 通断分析，开关清单按 `名称 · 状态 · 动作 · 影响` 四列呈现）· `动作过程`（**唯一的演练长文出处**：竖向时间轴，`0.00 s` 为故障发生时刻，之前是正常运行，故障发生时即刻高亮当前步）。**演练一旦开始（① 之后）自动切到「动作过程」**，标签右上角留橙色未读圆点；在画布上点选图元则回到「元件属性」。
- **③ 状态栏**：单行芯片——运行方式胶囊 +「环网闭环 / 开环」「母联常开 / 常合」、拓扑芯片（模板 / 电源 / 开关站 / 配电房 / 失电数）、校验 / 告警、以及**缩放 % / 图元数 / 当前主题**；放不下的横向滚动，长说明只出现在左栏「故障演练 / 右栏动作过程」里。
- **亮 / 暗主题**：右上角三态切换，写入 `localStorage`；「跟随系统」会随系统深色模式实时切换。主题通过 `data-theme` 挂到 `<html>`，画布（点阵底纹、阴影、文字描边、空心开关）也随主题重绘，电气语义色（花瓣Ⅰ/Ⅱ、合 / 分、失电、故障）两种主题下都清晰可辨。
- **画布**：左下角为**语义色图例**（花瓣Ⅰ带电 / 花瓣Ⅱ带电 / 合位 / 分闸 / 失电 / 故障点），右下角为缩放条（`−` / 百分比 / `＋` / 适应）。完整图元画法收在「帮助 → 接线约定 / 图元画法」。
- **选中反馈**：选中图元画 2px 虚线选中环（多选时逐个画），若不在视野内会自动滚入视区。
- **框选（CAD 语义）**：空白处拖框——**左 → 右**为「窗口选择」（完全框住才选中，蓝实线框）、**右 → 左**为「交叉选择」（碰到即选中，绿虚线框）；框内同时命中电缆与图元；配合 `Shift` 追加选择。
- **抓手平移**：画布光标默认是箭头（选择模式）；**按住空格**立刻变「小手」，此时在图元上拖动也是平移（不会误拖图元、不会误合分开关），松手即恢复；缩放条右端的手形按钮或「视图 → 抓手模式」可把抓手**锁定**（按钮变蓝）。平移过程中光标显示为「抓紧」的手。

## 搭网（元件库）

1. 左栏「网架结构」点 **自定义**（或点「空白网架 / 清空画布…」）→ 得到空白画布。
2. 从「元件库」把 **变电站 / 开关站 / 配电房 / 变压器 / 开关 / 母线** **拖到画布**（或直接点击，落在视图中央）。
   - 开关站会自动带出本站 4 个用户出线配电房；单独拖入的配电房会**自动挂到 150 px 内最近的一回用户出线**（可再拖动微调）。
   - 快捷键 **`C` / `Shift + C`** 可在元件库里前后轮换「待放置」元件，再在画布上单击落子（`Esc` 退出）。
3. 从图元的**端子**按住拖到另一个**端子**松手即成一根电缆（松手会自动吸附 22 px 内最近的端子）；也可**点一下端子 → 再点另一个端子**接线。
   拖动电缆本体可调整走线位置。**同一个图元的两个端子之间不允许互接**（电气上无意义，程序会拦下并提示）。
4. 右键图元：镜像 / 旋转 / 本站开关全合全分 / 设为故障点 / 重命名 / 删除；
   右键电缆：复位走线 / **设为常开联络（分位）** / 设为故障点 / 删除。
5. 「导出 JSON」保存整份网架（图元 + 电缆 + 开关状态 + 模板标识），「导入 JSON」原样载回——
   以后接真实线路只需换这份 JSON。

> 未接线的配电房按**失电**计（未供电），校验条会给出失电数，便于边搭边校。
> 拖动电缆/图元、旋转、复制粘贴、撤销（Ctrl+Z）、方向键微调等编辑能力对自建网架同样可用。

## 状态码与沙盘灯带

每一步动作都输出稳定状态码，便于映射灯带（通电亮、失电灭、故障闪、动作瞬间闪一下）：

```js
var st = window.__api.status();
// st.step  → IDLE | PROTECT | ISOLATE | RESTORE | DONE
// st.dev   → { A1:'ENERGIZED', A2:'DEENERGIZED', SUBA:'FAULT', … }
// st.sw    → { 'A1:bt':'SWITCH_OPEN', 'A1:u1':'SWITCH_CLOSED', … }   （TIE_CLOSED=联络合上）
// st.loads → { total:20, live:20, dead:0, lvAffected:0 }   （lvAffected = 失电建筑负荷数）
```

底栏芯片也会同步显示当前**状态码**。完整枚举、颜色对照与桥接示例见
[`docs/状态码与灯带映射.md`](docs/状态码与灯带映射.md)。

## 图元约定（与典型设计图一致）

- **变电站（10 kV 电源）**：**正方形**，内部竖置 10 kV 母线；**同一段母线**引出 2 回出线，
  电缆末端为**电缆终端头**（端子）并标注**示意性馈线编号**（如 出线1，不使用真实线路号），构成一片花瓣的两端电源。
- **开关站（环网柜）**：**单母线分段、不旋转、可上下镜像**——
  **Ⅰ 段母线（蓝）与 Ⅱ 段母线（青）共线横置**，中间为 **母联（分段开关，横置长条方框：空心=分位、实心=合位）**；
  母线外端为**母线终端**。每段母线 4 个间隔：
  **2 回用户出线（朝外）+ 2 回环网间隔（朝内，一进一出）**。
  断路器**实心 = 合位、空心 = 分位**；出线间隔朝向环网通道，用户间隔朝外。
- **配电房（用户负荷）**：**一个用户出线间隔 = 一个独立负荷**，各画**一个三角形**（顶点背向开关站），
  单电源供电；符号取所属母线段颜色（Ⅰ 段蓝 / Ⅱ 段青），**该回路失电即连同线路一起转灰**。
  每座开关站 4 个用户间隔；双花瓣中被样板配电房 / 环网箱占用的 3 个间隔不再重复画简化负荷，
  最终为 **14 个简化负荷点 + 6 个建筑负荷 = 20 个负荷点**。
- **样板配电房 DS1**：**虚线分组外框**，内部为两回独立 10 kV 进线 → 两台配变（T1 / T2）→
  0.4 kV 单母线分段（Ⅰ / Ⅱ段）→ 低压母联（常开 + 备自投）→ 4 回低压出线 → 6 个建筑负荷。
  **整组可拖动、复制、删除**，不参与旋转；低压设备与线路统一使用**琥珀色**。
- **环网箱 RM1**：**2 进 2 出**，四个 10 kV 间隔共用箱内母线；进线1 / 出线1 参与环网，
  进线2 / 出线2 为备用间隔（默认分位）。用于表示开闭站出线到配电房之间的分支节点。
- **建筑负荷**：**0.4 kV 单电源**，矩形建筑块 + 屋顶 / 门窗示意 + kW 数；一个建筑 = 一个独立负荷点，
  失电时建筑与进线一起转灰。
- **终端符号**：**电缆终端头** = 电缆末端的端子（白环 + 实心圆，不再画成箭头状）；**母线终端** = 母线末端的一个**小实心方块**（端头封堵）。
- **变压器（元件库里的独立元件）**：**双绕组变压器**符号——两个**相交的圆**（GB/T 4728.4 / IEC 60617）；
  **一次侧（高压）/ 二次侧（低压）各 1 个端子**，属**导体、恒通**（分合由两侧开关承担，变压器本身不是开关）。
- **开关（元件库里的独立元件）**：**长方形框**——**空心 = 分位（断开）、实心 = 合位（闭合）**；
  A / B 两端子，**单状态分合**（点框体即分 / 合；拖动框体是移动图元）。可**旋转 0° / 90°** 竖装，
  用作分段开关、联络开关、隔离开关；右键可「设为常开联络开关（常开）」，此时分位画成橙色虚线框。
- **母线（元件库里的独立元件）**：**加粗导体**，**左端 / 右端 / 中间引下共 3 个端子**，恒通、不可分断；
  用于自建单母线 / 单母线分段接线。
- **母联（分段开关）**：横置于两段母线之间，用**横置长条方框**表示，**空心 = 分位（断开）、实心 = 合位（闭合）**
  （双花瓣正常方式为分位/常开），两段母线互为备用。环间联络开关另用橙色虚线表示。

## 双花瓣网架（教科书方式）

- **命名**：全网**示意化命名**——变电站1 / 变电站2、开关站1~开关站4（开闭站）、配电房1~配电房14、
  建筑1~建筑6、样板配电房 DS1、环网箱1、出线1 / 出线2，不使用真实站名与线路号。
- **布置**：两座变电站分列左右，中间是**两排共 4 座开关站**——上排 2 座（开关站1~2，用户朝上）、
  下排 2 座（开关站3~4，用户朝下），环网间隔朝向两排之间的通道。
- **花瓣Ⅰ（变电站1）**：出线1 ⇒ 上排各站 **Ⅰ 段** ⇒ 开关站2 纵向联络 ⇒ 下排各站 **Ⅰ 段** ⇒ 出线2，成环运行。
- **花瓣Ⅱ（变电站2）**：出线1 ⇒ 上排各站 **Ⅱ 段** ⇒ 开关站1 纵向联络 ⇒ 下排各站 **Ⅱ 段** ⇒ 出线2，成环运行。
- **相切**：两片花瓣在每座开关站经**母联开关**相切；正常母联断开，两段互为备用（备自投）。
- **故障**：线路任一段故障由差动保护两端切除，合环运行下**非故障段不停电**；
  一段两路进线全失时，**母联备自投**由另一段接带其负荷。

### 运行方式与保护口径

- 正常方式：**环网合环运行 + 母联断开**；底栏“运行方式”与“校验 / 告警”**由环网开关、母联的真实位置驱动**，
  不再各说各话。双花瓣 / 单花瓣的各环由**同一电源的两回出线**构成，不存在环网开环点，
  故“环网闭环 / 开环”按钮对这两个模板置灰并说明；环网开环点由母联（花瓣间联络）承担，用“母联常开 / 常合”调整。
- 线路段故障：光纤电流差动保护**瞬时切除故障电缆两端开关**，合环运行下非故障段**不停电**。
- 开关站母线故障：母线差动保护跳开该段母线全部开关并**闭锁母联备自投**。
- **母联备自投（按站独立动作）**：故障后逐座检查，凡“一段母线失压、另一段有压”的开关站即合上本站母联，
  由另一段母线接带本站负荷；每合一处都校验**不并列、不向故障区间送电**。母线故障则整站母联被闭锁。
- 画布上的动作标注（①②③）会**自动避让**并画引线连回被标注的开关；右栏「动作过程」为**竖向时间轴**，
  以 `0.00 s` 故障发生为基准，之前为正常运行，之后为保护 / 隔离 / 转供各步。
- **三条入口同一状态机**：① 模拟故障 / ② 隔离故障 / ③ 转供恢复、**单步**、**自动演示**共用一套演练进度，
  任意入口在结束时，开关实态、失电负荷点数、步骤状态、时间轴文案**完全一致**；演练结束后再点“单步”会提示先复位。
- **场景库随拓扑切换**：双花瓣 / 单花瓣 / 双环网 / 单环网 / 单辐射各有对应场景与说明，“故障前”描述随模板生成。
- **拒动 / 越级**（K3 环网开关拒动、R1 出线保护拒动、M3 差动通道故障）按**后备保护越级**处理：
  跳开该段全部进出线并闭锁母联（或越级跳变电站出线），失电范围与文案同源。
- **备自投拒动**（M1）失压段无法转供；**转供容量不足**（M2）先复电、再见机**限电**，
  失电负荷点数与“只能转供 8 个负荷点”的说明一致。
- **故障性质**（F1 单相接地不跳闸 → 试拉确认；T1 重合成功；T2 重合不成功 → 加速跳闸后再隔离转供）。
- **运行方式**（O1 预置开环点；O2 母联常合并列 → 校验条告警）与**二次异常**（M4 保护误动 / 开关偷跳可直接强送）。
- **中低压协同**（LV1–LV4）：配变 T1 故障 → 高压侧与低压侧同时隔离，低压母联备自投由 T2 转带；
  0.4 kV 母线故障 → 闭锁低压备自投，禁止向故障母线反送；低压出线故障 → 只跳该出线，建筑失电待修复；
  两回 10 kV 进线全失 → 低压无备用电源，6 个建筑全失。

## 备份到 GitHub

仓库本身就是一个标准 git 仓库（分支 `main`，每个版本一个标签 `v1.x.y`）。因为工作台是**单文件零依赖**，
`.github/workflows/pages.yml` 已经配好：推到 `main` 即自动发 GitHub Pages，也能当在线 demo 用。

```bash
# ① 仓库已在 GitHub 建好（空仓库即可）——直接推送主干 + 全部标签
tools/push-to-github.sh git@github.com:<user>/<repo>.git

# ② 连仓库都没建——给一个 Token，脚本替你建（默认私有）并推送
tools/push-to-github.sh --create <user>/<repo> <TOKEN>          # 私有
tools/push-to-github.sh --create <user>/<repo> <TOKEN> public   # 公开
```

- **不想给 Token？用「部署密钥」**：在 GitHub 仓库 → `Settings` → `Deploy keys` → `Add deploy key`，
  贴入本机专用公钥 `~/.ssh/id_ed25519_doublepetal.pub` 并勾上 **Allow write access**（只授权这一个仓库）；
  `tools/push-to-github.sh` 检测到该密钥会自动用它发起 SSH 推送。（`Deploy key` 不能新建仓库，
  仓库需要你先在 GitHub 上建一个空的。）
- Token 只需 **classic PAT 的 `repo` 权限**（脚本只用来建仓库 / 推送；推送完成后 origin 会改写成**不含 Token** 的地址，Token 不会留在 `.git/config`，也不回显）。
- 也可以用 SSH：把本机公钥（`~/.ssh/id_ed25519.pub`）加到 GitHub → Settings → SSH keys，
  再用 `git@github.com:<user>/<repo>.git` 推送。
- 本地只推 `main` / `--all` / `--tags`，不修改任何提交历史。
