# 双花瓣配电网 · 仿真工作台

面向 **10 kV 中压配电网典型接线** 的可编辑、可仿真、可演练的单页工作台。
零依赖、零构建，双击 `index.html` 即可运行（推荐 Chrome / Edge）。

## 快速开始

```bash
# 方式一：直接打开
open index.html            # macOS
start index.html           # Windows

# 方式二：起一个本地静态服务（推荐，避免个别浏览器对 file:// 的限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080/
```

## 界面布局

```
┌──────────────────────────────────────────────────────────────┐
│ 菜单栏  文件 编辑 视图 拓扑 演练 帮助 │ 常用工具栏          │  顶栏
├───────────┬──────────────────────────────┬───────────────────┤
│ 拓扑模板   │                              │ 图元属性 · 编辑    │
│ 故障场景库 │          绘图 / 仿真画布       │ 通断分析           │
│ 图例(可折叠)│         （可缩放 / 平移）      ├───────────────────┤
│           │                              │ 动作过程 ① ② ③    │
├───────────┴──────────────────────────────┴───────────────────┤
│ 运行状态                              │ 校验 / 告警            │  底栏
└──────────────────────────────────────────────────────────────┘
```

- **顶栏**：菜单（文件 / 编辑 / 视图 / 拓扑 / 演练 / 帮助）+ 高频按钮 + 图元大小滑杆。
- **底栏**：左侧「运行状态」（当前模板、电源/开关站/配电房数量、失电数、运行方式），右侧「校验 / 告警」（并列、开环、备用间隔等）。
- **右栏**：上半区为选中图元的属性与**通断分析**（开关分合、上下游带电、转供路径），下半区为**动作过程**时间线。
- 画布右下角为缩放条（`−` / 百分比 / `＋` / 适应）。

## 图元约定（与典型设计图一致）

- **变电站（10 kV 电源）**：**正方形**，内部竖置 10 kV 母线；**同一段母线**引出 2 回出线，
  出线端头画**线路终端**并标注**示意性馈线编号**（如 出线1，不使用真实线路号），构成一片花瓣的两端电源。
- **开关站（环网柜）**：**单母线分段、不旋转、可上下镜像**——
  **Ⅰ 段母线（蓝）与 Ⅱ 段母线（青）共线横置**，中间为 **母联（分段开关，方框：空心=分位、实心=合位）**；
  母线外端为**母线终端**。每段母线 4 个间隔：
  **2 回用户出线（朝外）+ 2 回环网间隔（朝内，一进一出）**。
  断路器**实心 = 合位、空心斜置 = 分位**；出线间隔朝向环网通道，用户间隔朝外。
- **配电房（用户）**：**每一回用户出线各自带一个三角形负荷符号**（顶点背向开关站），表示该间隔已接入负荷；
  双回路进线两回引自本站同一段母线的两回用户出线间隔，任一回带电即不停电（分支电缆故障只损失一路，用户不停电）；
  符号取所属母线段颜色（Ⅰ 段蓝 / Ⅱ 段青）。
- **终端符号**：**线路终端** = 实心端子 + 两侧箭头（电缆终端头）；**母线终端** = 母线末端的一个**小实心方块**（端头封堵）。
- **母联（分段开关）**：横置于两段母线之间，用**方框**表示，**空心 = 分位（断开）、实心 = 合位（闭合）**
  （双花瓣正常方式为分位/常开），两段母线互为备用。环间联络开关另用橙色虚线表示。

## 双花瓣网架（教科书方式）

- **命名**：全网**示意化命名**——变电站1 / 变电站2、开关站1~开关站9、配电房1 / 配电房2 …、出线1 / 出线2，
  不使用真实站名与线路号。
- **布置**：两座变电站分列左右，中间是**两排共 9 座开关站**——上排 5 座（开关站1~5，用户朝上）、
  下排 4 座（开关站6~9，用户朝下），环网间隔朝向两排之间的通道。
- **花瓣Ⅰ（变电站1）**：出线1 ⇒ 上排各站 **Ⅰ 段** ⇒ 开关站5 纵向联络 ⇒ 下排各站 **Ⅰ 段** ⇒ 出线2，成环运行。
- **花瓣Ⅱ（变电站2）**：出线1 ⇒ 上排各站 **Ⅱ 段** ⇒ 开关站1 纵向联络 ⇒ 下排各站 **Ⅱ 段** ⇒ 出线2，成环运行。
- **相切**：两片花瓣在每座开关站经**母联开关**相切；正常母联断开，两段互为备用（备自投）。
- **故障**：线路任一段故障由差动保护两端切除，合环运行下**非故障段不停电**；
  一段两路进线全失时，**母联备自投**由另一段接带其负荷。

### 运行方式与保护口径

- 正常方式：**环网合环运行 + 母联断开**（工具栏可切换“环网开环 / 环网闭环”）。
- 线路段故障：光纤电流差动保护**瞬时切除故障电缆两端开关**，合环运行下非故障段**不停电**。
- 开关站母线故障：母线差动保护跳开该段母线全部开关并**闭锁母联备自投**。
- **母联备自投（按站独立动作）**：故障后逐座检查，凡“一段母线失压、另一段有压”的开关站即合上本站母联，
  由另一段母线接带本站负荷；每合一处都校验**不并列、不向故障区间送电**。母线故障则整站母联被闭锁。
- 画布上的动作标注（①②③）会**自动避让**并画引线连回被标注的开关；右栏「动作过程」为**竖向时间轴**，
  以 `0.00 s` 故障发生为基准，之前为正常运行，之后为保护 / 隔离 / 转供各步。

详见 [`docs/接线约定.md`](docs/接线约定.md)。

## 发布到 GitHub

本仓库已做好完整的 Git 版本管理（含提交历史与版本标签），但本机无 GitHub 凭据，**首次推送**需你在 GitHub 上建好空仓库后执行：

```bash
cd 本项目目录
git remote add origin git@github.com:<你的用户名>/<仓库名>.git
git push -u origin main --tags
```

若使用 HTTPS：

```bash
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main --tags
```

> 本机 SSH 公钥请执行 `cat ~/.ssh/id_ed25519.pub` 获取，加到 GitHub → Settings → SSH and GPG keys 后即可免密推送。
